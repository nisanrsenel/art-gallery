# 🖼️ Art Gallery Website

## 🎨 Proje Hakkında / About the Project

Bu proje, sanatçının eserlerini dijital ortamda etkileyici bir şekilde sunmak amacıyla tasarlanmıştır. Scroll efektli ana sayfa ve navbar üzerinden erişilebilen diğer sayfalar ile kullanıcıya hem bilgi hem de ilham sunar. / This project was designed to present the artist's works in an impressive digital environment. With a scrolling homepage and other pages accessible via the navbar, it offers users both information and inspiration.

### 🔍 Özellikler / Features

- 🌐 **Dil Seçenekleri** / **Language Options**
  - Türkçe 🇹🇷  
  - İngilizce 🇬🇧

- 🖌️ **Sanatçı Portfolyosu** / **Artist Portfolio**
  - Yağlı boya eserlerin görselleri / Images of oil paintings
  - Sanat nesneleri hakkında açıklamalar / Descriptions of the art objects

- 📞 **İletişim Bilgileri** / **Contact Information**
  - Sanatçıya ulaşmak için iletişim formu ve bilgiler

- 📜 **Scroll Efektli Ana Sayfa** / **Homepage with Scroll Effect**
  - Estetik geçişlerle kullanıcıyı karşılayan açılış / A welcoming opening with aesthetic transitions

## 🛠️ Kullanılan Teknolojiler / Technologies Used

- **HTML5** – Sayfa yapısı / Page structure
- **CSS3** – Stil ve geçiş efektleri / Style and transition effects
- **JavaScript** – Etkileşim ve dil geçişleri / Interaction and language transitions

> Toplamda:
> - **10 HTML sayfası** (bazıları iç CSS ve JS içeriyor) / **10 HTML pages** (some contain internal CSS and JS)
> - **2 harici CSS dosyası** / **2 external CSS files**
> - **1 harici JavaScript dosyası** / **1 external JavaScript file**
